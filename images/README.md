## 小提醒

- 檔名要完全一樣，全部小寫，副檔名是 `.jpg`。
- 橫向的照片最好看（比例約 16:9 或 4:3），網站會自動置中裁切成卡片大小。
- 單張建議在 300KB 以內，手機載入比較快。
- 請放自己拍的照片，或有授權可以使用的照片。
